# StrideBR sports icons

These SVGs are local project assets drawn specifically for StrideBR to keep the sports icon style consistent.

## Style rules
- 24x24 viewBox
- outline style
- `fill="none"`
- `stroke="currentColor"`
- `stroke-width="2"`
- rounded linecap and linejoin

## Notes
- Generic interface icons still use local Tabler Icons under `public/assets/icons/tabler/`.
- Sports icons in this folder are custom StrideBR assets and may be edited freely inside the project.
