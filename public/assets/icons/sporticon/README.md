# Sporticon assets

Sports pictograms in this directory are extracted from **Player! Sporticon** by ookami.

- Source: https://github.com/ookamiinc/Sporticon
- License: Apache License 2.0 (see `LICENSE.txt`)
- The original SVG sprite was split into individual SVG files for use inside StrideBR.
- Geometry is unchanged; the standalone wrapper uses `fill="currentColor"` so the pictograms follow the interface color.
