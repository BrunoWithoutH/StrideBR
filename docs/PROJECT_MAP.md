# Ecossistema StrideBR

## Produtos

- **StrideBR**: [BrunoWithoutH/StrideBR](https://github.com/BrunoWithoutH/StrideBR), em [stridebr.com.br](https://stridebr.com.br); produto individual gratuito e open source.
- **StrideBR Teams**: [BrunoWithoutH/StrideBR-Teams](https://github.com/BrunoWithoutH/StrideBR-Teams), domínio planejado `teams.stridebr.com.br`; produto institucional pago em desenvolvimento separado.

## Identidade

Há uma única conta StrideBR para Core, Teams e futuros produtos. Memberships, papéis institucionais e entitlements não são contas separadas. O mecanismo técnico futuro de autenticação/SSO permanece aberto.

## Fontes canônicas

Este repositório é canônico para Core: implementação atual, atividades, cronogramas, Trainer individual, GPS, progresso, integrações, identidade atualmente implementada e infraestrutura atual.

O repositório Teams é canônico para produto Teams, organizações, equipes, memberships, papéis institucionais, billing, data ownership, MVP 2027, UX, arquitetura Teams e integração institucional Core ↔ Teams.
